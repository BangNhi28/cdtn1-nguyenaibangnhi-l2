# Minh chứng ảnh chụp test

Đặt tên theo mã test case trong `docs/test-report.md`:

- `TC-01.png` … `TC-12.png`
- `npm-test.png` — kết quả terminal `npm test`
- `BUG-01-fixed.png` — xác nhận sau sửa bug (tùy chọn)

Ảnh phải thấy rõ **lệnh đã chạy** và **kết quả** (terminal, Postman, hoặc màn hình).

Test case **không có ảnh** tại đây → coi là **không có minh chứng** (buổi 14 / BT3).
